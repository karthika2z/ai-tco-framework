What is modelled — and what is not

Modelled: tokens/compute, hosting, security & compliance, process failure & rework, residual human oversight, hosting infrastructure, and change-management overhead. All figures are per-role, per-year, in 2026 USD.

Not modelled: revenue upside, hiring premia, one-time migration costs, or company-specific regulatory obligations. Add those to your own copy of the calculator — the source is open.

Provenance

Every row is produced by driving the actual DroidWork TCO calculator with each function/level combination and capturing the resulting state. The extractor is seo/extract-role-data.mjs. Reproduce with:

git clone https://github.com/karthika2z/ai-tco-framework
cd ai-tco-framework
npm install
node seo/extract-role-data.mjs
